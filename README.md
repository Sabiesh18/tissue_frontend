# Tissue Manufacturing Management System - Frontend

Modern, responsive web client for the Tissue Manufacturing Management System built with **React**, **TypeScript**, **Vite**, and **Tailwind CSS**.

## Theme & Palette Specifications
- **Application Background:** Primary Light Pink (`#DF538B`)
- **Action Buttons & Highlights:** Primary Dark Pink (`#D8276D`)
- **Containers & Cards:** Pure White (`#FFFFFF`)
- **Typography & Icons:** High Contrast Black (`#000000`)

## Modules Implemented
1. **Interactive Dashboard:** Live production summaries, 7-day plant trend analysis, asset health, and stock alerts.
2. **Manufacturing & Batches:** Production planning, batch scheduling, shift management, and automated output logging.
3. **Inventory & Raw Materials:** Virgin pulp parent reel tracking, packing films, cores, and stock adjustment logs.
4. **Plant Machinery & Assets:** Machinery registration, serial numbers, operational health monitoring, and maintenance.
5. **Vendors & Suppliers:** Supplier directory, payment terms, and contact records.
6. **Customers & Accounts:** Hospitality, hospital, supermarket, and wholesale distributor accounts.
7. **Commercial Orders:** Finished goods sales orders and supplier purchase orders.
8. **Settings & Administration:** User management, role access, system parameters, and immutable activity logs.

## Running Locally
```bash
npm install
npm run dev
```
Accessible at: `http://localhost:3000`
Default login credentials: `admin` / `admin123`
